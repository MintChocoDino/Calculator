What it does

Deliberately small. These are all of the features.

+−

The four operations

Add, subtract, multiply and divide, evaluated left to right, with percent and sign toggle.

⌨

Full keyboard control

Number row, operators, Enter to equal, Backspace to delete, Esc to clear.

⇲

Resizes properly

Drag it to any size you like. The keypad scales with the window instead of clipping.

0

Honest numbers

0.1 + 0.2 shows 0.3, not floating-point noise. Division by zero says so plainly.

Installing

Per-user install. It never asks for an administrator prompt.

  1. Run SandboxCalculator-1.0.0-Setup.exe.
  2. Pick a folder, and optionally tick Create a desktop shortcut.
  3. Finish — the app lands in your Start Menu as Sandbox Calculator.
  4. To remove it later: Settings → Apps, or the bundled unins000.exe.
